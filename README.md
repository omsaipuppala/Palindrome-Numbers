# Palindrome Numbers

Name:Puppala Omsai

Programming Language:Python

#Problem Description

Write a program to check whether a given number or string
is a palindrome or not.
  ->A palindrome reads the same forward and backward.

#How to Run the Program

1. Open the project folder in VS Code or IDLE.
2. Run the code F5
3. Enter a number or string when prompted.

#Sample Input and Output

#Example 1
Input:madam

Output:Palindrome

# Example 2
Input:hello

Output:Not a Palindrome

#Example 3
Input:121

Output:Palindrome
